# SpecBattle

> Your Phone vs Mine. Let the Specs Decide.

SpecBattle is a web application for comparing Android phones using structured specifications, transparent scoring, and category-by-category battles.

## MVP Scope

- Web application
- Android phones only as comparison products
- Search and select two phones
- Compare specifications
- Category winners
- Overall score and winner
- Shareable battle results
- Admin management of phone data

## SDLC
